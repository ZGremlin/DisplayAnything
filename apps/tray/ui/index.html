      Keys and mouse buttons both work, for example Ctrl + Mouse Back. Using the same combination for switching over and coming back makes it a toggle.

      Edge crossing

      Set this on the computer whose keyboard and mouse you're using. Push a little past the edge to cross; it won't cross while you're dragging something. Set the opposite side on the other computer to cross back the other way too.
